## Progression Rule

The table defines ownership of the 3,600 core batch numbers, not an immutable lesson script. The exact content of a future core batch is generated only when it is reached and after repository state is inspected.

## Dynamic Batch Rule

A dynamic batch uses a star identifier such as:

- ⭐ DYN-0001
- ⭐ DYN-0002

Dynamic batches are inserted only when evidence shows they are needed. Examples include a missing prerequisite, a failed experiment that requires investigation, a security gap, a build-order correction, or an important new technique that materially changes the journey.

The next core batch number remains unchanged until its prerequisite dynamic work is complete.

# Batches

Batch records are added here only when they are actually generated.

Recommended structure:

```text
batches/
  track-01-ai-landscape/
    batch-0001/
      README.md
    batch-0002/
      README.md
  track-02-computer-science/
    ...
  dynamic/
    dyn-0001/
      README.md
```

Do not pre-create 3,600 empty directories. Create each batch directory when the batch begins so the repository reflects real progress rather than placeholders.
